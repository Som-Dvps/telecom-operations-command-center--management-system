# SSNMS Thesis and Implementation Blueprint

## Project Definition

The Somnet Smart Network Management System is an intelligent telecom governance platform that combines FCAPS monitoring, Jeeb financial continuity protection, cybersecurity monitoring, and predictive analytics.

## Research Methodology

Research design: mixed method.

Data collection: interviews with NOC engineers, direct observation, existing incident logs, Jeeb transaction failure records, and firewall/security event samples.

Sampling: Somnet IT staff, NOC engineers, security admins, Jeeb service managers, and operations executives.

Data analysis: comparative downtime analysis, system performance metrics, alert response time, transaction failure trends, and user acceptance testing.

## UML Expansion

Recommended diagrams:

- Use Case Diagram: NOC Engineer, Security Admin, Jeeb Service Manager, Executive Manager, System Admin
- Deployment Diagram: browser, Apache/PHP, MySQL, routers, BTS, Jeeb API, firewall logs
- ERD: users, devices, alerts, network logs, Jeeb transactions, fraud alerts, security logs, analytics logs, reports, settings
- DFD: device/security/transaction inputs to monitoring engines and reporting outputs
- Sequence Diagram: device anomaly to AI prediction to alert to NOC resolution
- Activity Diagram: incident detection, triage, escalation, resolution, reporting

## Master Conclusion

The Somnet Smart Network Management System is a next-generation intelligent telecom governance platform engineered to transform Somnet from reactive operational dependency into predictive digital sovereignty. By integrating AI-powered monitoring, Jeeb financial protection, centralized FCAPS governance, and scalable 4G/5G infrastructure management, SSNMS provides a secure technological backbone for Somalia's communications, commerce, and national digital resilience.
